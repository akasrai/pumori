# PRD: Tiny To-Do

People need a simple personal to-do list they can reach from any browser.

- Users sign up and log in with email and password.
- A user has one list of to-dos. Each to-do has a title (1–200 characters) and can be marked done or not done.
- Users can add, edit the title of, complete/uncomplete and delete their to-dos.
- The list shows open to-dos first (newest first), then completed ones.
- A counter shows how many to-dos are still open.
- Users only ever see their own to-dos.
