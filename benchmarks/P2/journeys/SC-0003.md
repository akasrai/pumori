## Goal
See whether another person's notes or tags leak.
## Story
User A creates a note "Salary negotiation" tagged "private-hr". User B signs up, searches "salary",
looks at the tag filter list, and tries direct URLs/API calls with A's note id (read, edit, archive, delete).
## Satisfied when
- B finds nothing, never sees the tag "private-hr", and all attempts on A's note fail without revealing it.
## Not satisfied if
- Anything of A's is visible or modifiable by B.
