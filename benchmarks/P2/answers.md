# Pre-answered questions (benchmark P2)
- No rich text, attachments, sharing or collaboration (non-goals).
- Tags are created implicitly by typing them on a note; unused tags disappear from the filter list.
- Search covers archived notes only in the Archive view.
- Autosave on edit is expected (no explicit save button needed), but an explicit save is acceptable.
- For any other question, accept the PM's proposed default.
